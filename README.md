# SONA

Веб-кинотеатр вертикальных AI-сериалов. Next.js App Router, TypeScript, TanStack Query, shadcn/ui, Animate UI и CSS Modules. Страницы находятся в `src/_pages`, сессия и каталог в `src/entities`, транспорт и типы в `src/shared/api`. Каталог `app` задаёт маршруты веба и same-origin обработчики запросов браузера.

## Локальный запуск

`npm ci` устанавливает зависимости. `npm run dev` запускает сайт. Проверки — `npm test`, `npm run typecheck` и `npm run build`. Для Web Locks и защищённых API браузера нужен HTTPS или localhost.

## Контракт веб-клиента

Контракт веб-клиента описан в `api/openapi.yaml` и содержит 39 операций. После изменения выполните `npm run api:generate`. Адрес сервера задаёт `SONA_API_ORIGIN`.

| Возможность | Веб-интеграция |
| --- | --- |
| Аккаунт и сессии | Гость, регистрация и вход по email, обновление и завершение сессии, настройки профиля и устройства |
| Поиск и каталог | Главная, лента, поиск, каталог, карточка сериала, список серий и события |
| Просмотр | Подписанный адрес, проверка доступа, разблокировка, дневные открытия, прогресс и история |
| Коллекция | Добавление и удаление лайка и закладки, список избранного |
| Кошелёк | Баланс, журнал, продукты, Stripe Checkout |
| Награды | Состояние и получение ежедневной награды, серия дней просмотра |
| Уведомления | Чтение и изменение настроек по категориям, привязка и удаление токена устройства |

Для регистрации нужен пароль длиной 15–128 символов и код из письма. При следующем входе пользователь вводит email и пароль. Действующий гостевой токен сервер передаёт при входе или подтверждении регистрации. Токены сессии хранятся в HttpOnly cookies. Для старого аккаунта с активным сеансом доступна привязка почты на `/login?link=email`. Публичный ключ Turnstile задаётся через `NEXT_PUBLIC_TURNSTILE_SITE_KEY`.

## Просмотр и профиль

На главной выбор настроения меняет заголовок, кадр, акцент и подборку. Поиск раскрывается в шапке и показывает результаты на месте. Закладка на обложке сохраняет сериал без перехода. В профиле можно вернуться к последнему просмотру, открыть коллекцию и выбрать типы уведомлений.

На телефоне плеер показывает один активный эпизод. Список серий открывается поверх кадра. На компьютере панель воспроизведения и очередь доступны рядом с видео. Сервер определяет доступ к каждой серии. Предзагрузка следующего доступного эпизода зависит от соединения и настройки экономии трафика. Кэш TanStack Query разделён по текущей сессии, а после смены пользователя очищается.

Для веб-пушей нужны настройки Firebase Web и ключ VAPID из `.env.example`, а также разрешение пользователя в поддерживаемом браузере.

## Языки и поисковая индексация

Интерфейс поддерживает русский и английский. Переключатель в настройках и подвале сохраняет выбор в браузере. Публичные ссылки с `?lang=ru` и `?lang=en` открывают соответствующую версию без предварительного выбора языка. Предпочтительный язык названий сериалов задаётся отдельно в профиле.

Публичный адрес кинотеатра — `https://sona-ai.watch`. Он используется в canonical, языковых ссылках, Open Graph и `/sitemap.xml`. В другой среде его можно переопределить через `SONA_SITE_ORIGIN`. Для чтения опубликованных сериалов сервер использует гостевую установку. Необязательная `SONA_CATALOG_DEVICE_ID` задаёт её постоянный UUID для конкретной среды. Карточки имеют адрес `/series/{id}-{slug}`. Числовые адреса продолжают работать и сохраняют параметры просмотра при перенаправлении.

## Docker и Traefik

Создайте на сервере `.env` по образцу `.env.example`. Укажите публичное имя оператора в `SONA_OPERATOR_NAME` и действующий адрес поддержки в `SONA_SUPPORT_EMAIL`. Они появятся на страницах `/privacy`, `/terms` и `/help`. Сверьте текст о персональных данных с фактической практикой оператора, включая сроки хранения серверных данных и применимые права зрителей.

У активного DNS-провайдера задайте две записи `A` — хосты `@` и `www` указывают на `157.22.140.70`. Запись `AAAA` нужна только для работающего IPv6 того же сервера. Traefik перенаправляет `www.sona-ai.watch` на `https://sona-ai.watch` с сохранением пути и параметров ссылки. Порты 80 и 443 должны быть доступны из интернета. Приложение слушает порт 3000 внутри Docker.

**Если на сервере уже есть Traefik с Docker provider**, заполните `TRAEFIK_NETWORK` и `TRAEFIK_CERT_RESOLVER` именами из его конфигурации. При необходимости задайте `TRAEFIK_HTTP_ENTRYPOINT` и `TRAEFIK_HTTPS_ENTRYPOINT` (по умолчанию `web` и `websecure`).

```sh
docker compose -f compose.yaml -f compose.external.yaml config --quiet
docker compose -f compose.yaml -f compose.external.yaml up -d --build
```

**На новом сервере** заполните `ACME_EMAIL` адресом администратора для Let's Encrypt. Комплектный Traefik перенаправляет HTTP на HTTPS и получает сертификат через HTTP-01. Ключи и сертификаты хранятся в томе `sona-web_certificates`; сохраняйте его при обновлениях.

```sh
docker compose -f compose.yaml -f compose.edge.yaml config --quiet
docker compose -f compose.yaml -f compose.edge.yaml up -d --build
```

После запуска проверьте `curl -I http://sona-ai.watch/privacy` и `curl -I "https://www.sona-ai.watch/privacy?lang=en"`. Во втором случае заголовок `Location` должен содержать `https://sona-ai.watch/privacy?lang=en`. Проверьте ответы основного сайта на `/privacy`, `/robots.txt` и `/sitemap.xml`. При использовании Stripe настройте адреса возврата в платёжном бэкенде для нового домена; проверьте список разрешённых доменов у подключённых поставщиков. Публичные параметры `NEXT_PUBLIC_*` встраиваются при сборке, после их изменения пересоберите образ.

## Покупки

`/shop` запрашивает витрину для web. Витрина возвращает SKU, а Stripe Checkout ожидает UUID товара. Задайте соответствие в серверной переменной `SONA_WEB_PRODUCT_IDS`. Монеты и история операций обновляются по данным сервера после подтверждения платежа.
