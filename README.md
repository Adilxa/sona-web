# SONA

Веб-кинотеатр вертикальных AI-сериалов. Next.js App Router, TypeScript, TanStack Query, shadcn/ui, Animate UI и CSS Modules. Страницы находятся в `src/_pages`, сессия и каталог в `src/entities`, транспорт и типы в `src/shared/api`. Каталог `app` задаёт маршруты веба и same-origin обработчики запросов браузера.

## Локальный запуск

`npm ci` устанавливает зависимости. `npm run dev` запускает сайт. Проверки — `npm test`, `npm run typecheck` и `npm run build`. Для Web Locks и защищённых API браузера нужен HTTPS или localhost.

## Контракт веб-клиента

Контракт веб-клиента описан в `api/openapi.yaml` и содержит 39 операций. После изменения выполните `npm run api:generate`. Адрес сервера задаёт `SONA_API_ORIGIN`.

| Возможность | Веб-интеграция |
| --- | --- |
| Аккаунт и сессии | Гость, регистрация и вход по email, обновление и завершение сессии, настройки профиля и устройства |
| Поиск и каталог | Главная, лента, поиск, каталог, карточка сериала, список серий и события |
| Просмотр | Подписанный адрес, проверка доступа, разблокировка, дневные открытия, прогресс и история |
| Коллекция | Добавление и удаление лайка и закладки, список избранного |
| Кошелёк | Баланс, журнал, продукты, Stripe Checkout |
| Награды | Состояние и получение ежедневной награды, серия дней просмотра |
| Уведомления | Чтение и изменение настроек по категориям, привязка и удаление токена устройства |

Для регистрации нужен пароль длиной 15–128 символов и код из письма. При следующем входе пользователь вводит email и пароль. Действующий гостевой токен сервер передаёт при входе или подтверждении регистрации. Токены сессии хранятся в HttpOnly cookies. Для старого аккаунта с активным сеансом доступна привязка почты на `/login?link=email`. Публичный ключ Turnstile задаётся через `NEXT_PUBLIC_TURNSTILE_SITE_KEY`.

## Просмотр и профиль

На главной выбор настроения меняет заголовок, кадр, акцент и подборку. Поиск раскрывается в шапке и показывает результаты на месте. Закладка на обложке сохраняет сериал без перехода. В профиле можно вернуться к последнему просмотру, открыть коллекцию и выбрать типы уведомлений.

На телефоне плеер показывает один активный эпизод. Список серий открывается поверх кадра. На компьютере панель воспроизведения и очередь доступны рядом с видео. Сервер определяет доступ к каждой серии. Предзагрузка следующего доступного эпизода зависит от соединения и настройки экономии трафика. Кэш TanStack Query разделён по текущей сессии, а после смены пользователя очищается.

Для веб-пушей нужны настройки Firebase Web и ключ VAPID из `.env.example`, а также разрешение пользователя в поддерживаемом браузере.

## Покупки

`/shop` запрашивает витрину для web. Витрина возвращает SKU, а Stripe Checkout ожидает UUID товара. Задайте соответствие в серверной переменной `SONA_WEB_PRODUCT_IDS`. Монеты и история операций обновляются по данным сервера после подтверждения платежа.
